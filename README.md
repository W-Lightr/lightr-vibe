# lightr-vibe

一个面向本地开发的 AI 编码工作台：在同一个桌面应用里与 AI Agent 对话、浏览和编辑代码、运行终端、管理任务，并把重复工作交给自动化与子代理。

## 核心功能

### AI 对话

- 支持 **OpenCode、Claude Code、Codex** 三种 Agent，每个会话可独立选择引擎。
- 流式展示回答与思考过程，支持 Markdown 渲染、代码高亮与复制。
- 工具调用以卡片形式呈现，可查看参数、执行状态与结果。
- Agent 制定计划时展示计划清单，并实时更新每一步的状态。
- 需要授权时弹出权限卡，显示操作目标与说明，可选择允许或拒绝。
- Agent 向你提问时弹出提问卡，支持单选、多选和自由文本回答。
- 随时停止生成，立即收尾当前回答。
- 显示上下文用量与每轮统计，便于判断何时需要压缩或新建会话。
- 支持切换模型、思考强度与运行模式。

### 编码工作区

- 项目文件树，支持快速浏览与打开文件。
- 内置代码编辑器，支持语法高亮、多文件标签与未保存提示。
- 集成终端，可直接运行命令并查看输出。
- Diff 预览与变更查看，方便确认 Agent 修改了什么。
- 会话标签页，可在多个对话之间快速切换。
- 消息队列：生成过程中可以继续输入，消息会按顺序发送。

### 会话管理

- 本地保存会话历史，重启应用后可继续之前的对话。
- 恢复 Agent 侧历史上下文，继续对话时不丢失前文。
- 会话自动命名，也支持手动重命名与删除。
- 按项目/文件夹组织会话，快速定位历史工作。

### 任务看板

- 按项目查看任务，支持待办、进行中、完成等状态流转。
- 新建、编辑、删除任务，记录标题、描述与优先级。
- 任务与编码会话相互独立，可边看任务边推进实现。

### 自动化

- 创建定时任务，让 Agent 在无人值守时自动执行。
- 每次运行保留状态、耗时与结果摘要。
- 运行记录可回看，并支持恢复对应会话继续处理。
- 适合周期检查、批量整理、定时生成等重复工作。

### 子代理委派

- 主会话可以把子任务派给子代理并行处理。
- 右侧栏实时查看子任务进度、状态与结果摘要。
- 子任务拥有独立会话，不打断主对话。
- 支持取消子任务，避免后台继续修改文件。

### Git 协作

- 查看当前分支与工作区状态。
- 支持创建和使用 worktree，在隔离目录中开展工作。
- 汇总并提交变更，减少在终端与编辑器之间来回切换。

### 设置与 Agent 管理

- 独立设置窗口，不打断当前工作区。
- 查看已安装的 Agent，管理引擎与默认行为。
- 管理模型配置、环境变量与权限策略。

## 典型使用流程

1. 打开一个项目文件夹。
2. 新建会话并选择 Agent。
3. 描述需求，Agent 开始分析、制定计划并执行。
4. 在权限卡中确认敏感操作，在计划卡中查看进度。
5. 在文件树、编辑器和 Diff 中检查改动，在终端中运行验证。
6. 需要并行处理时派发子任务，或把重复工作交给自动化。
7. 完成后提交变更，会话历史会自动保留，便于下次继续。

## 界面组成

- **左侧栏**：项目、会话列表、任务与自动化入口。
- **中间工作区**：对话、文件编辑器、Diff 与终端。
- **右侧面板**：计划、工具详情、子任务、上下文用量与会话信息。
- **顶部栏**：引擎与模型选择、运行模式、窗口控制。

## 支持的 Agent

| Agent | 能力 |
|---|---|
| OpenCode | 对话、工具调用、计划、权限、提问、配置切换 |
| Claude Code | 对话、思考、工具调用、计划、权限、提问、历史恢复 |
| Codex | 对话、工具调用、计划、权限、提问 |

不同 Agent 的具体能力以其自身实现为准；应用会在缺失或不可用时给出提示。
