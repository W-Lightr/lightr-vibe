# PRD: 待办任务项目选择页

父任务：`10-21-task-project-picker`。设计：`../10-21-task-project-picker/design.md` §2。

## Goal

从侧栏点「待办任务」时，先看到的是**按项目铺开的卡片**；选中一个项目才进入它的四列看板。
新建任务时项目已经确定，不必再选一次。

## Requirements

### R1 项目卡片页
- 路由 `/tasks` 渲染新的项目选择页。
- 顶部：标题「待办任务」+ 右侧「新建任务」按钮。
- 搜索框：按项目名与根路径过滤（大小写不敏感）。
- 卡片网格：每个已打开项目一张卡；`sm:grid-cols-2 lg:grid-cols-3 xl:grid-cols-4`。
- 卡片内容：文件夹图标 + 项目名 + `N 个任务` + 四列计数（待办 / 进行中 / 等你处理 / 已完成）。
- 「全部项目」卡片固定排在最后。

### R2 进入看板
- 点项目卡片 → `/tasks/:projectId`。
- 点「全部项目」→ `/tasks/all`。
- 看板页顶部有返回按钮回到 `/tasks`。

### R3 看板以项目为准
- `TasksView` 的项目来自路由参数，不再读 localStorage 筛选。
- 移除看板顶部原有的「项目下拉筛选」。
- 顶栏显示当前项目名（`全部项目` 时为「全部项目」）。
- 项目不存在（被移除）且不是 `all` → 显示「项目已移除」+ 返回项目选择页。

### R4 新建任务默认项目
- 看板页（具体项目）的「新建任务」：编辑器预选该项目，且创建模式下该选择不可更改。
- 项目卡片页的「新建任务」：不预选，需用户选择。
- 「全部项目」看板的「新建任务」：不预选。

### R5 空状态
- 没有任何项目 → 「还没有打开任何文件夹」+「打开文件夹」按钮（复用现有目录选择与加入逻辑）。
- 搜索无匹配 → 「没有匹配的项目」。

## Acceptance Criteria

- [ ] **AC1** 侧栏点「待办任务」进入项目卡片页，卡片数量等于已打开项目数（含「全部项目」卡）。
- [ ] **AC2** 卡片显示项目名、任务总数、四列计数；无任务的项目显示 `0 个任务`。
- [ ] **AC3** 搜索输入项目名片段能实时过滤；搜索根路径片段也能命中。
- [ ] **AC4** 搜索无匹配时显示「没有匹配的项目」。
- [ ] **AC5** 点项目卡片进入 `/tasks/:projectId`，看板只显示该项目任务。
- [ ] **AC6** 点「全部项目」进入 `/tasks/all`，看板显示所有项目任务。
- [ ] **AC7** 看板顶部有返回按钮，点击回到 `/tasks`。
- [ ] **AC8** 从项目看板点「新建任务」，编辑器里项目已预选且不可切换。
- [ ] **AC9** 从项目卡片页 / 全部项目看板新建任务时，项目未预选、可选择。
- [ ] **AC10** 访问一个已移除项目的 `/tasks/xxx` 时显示「项目已移除」并可返回。
- [ ] **AC11** 看板拖拽、隐藏已取消/已归档开关、详情、启动/停止/审核等既有功能零回归。
- [ ] **AC12** `vue-tsc --noEmit` + `pnpm build` 绿。

## Out of Scope

- 项目卡片上的排序 / 拖拽 / 右键菜单
- 任务列表视图
- 项目的创建 / 删除（卡片页只提供「打开文件夹」）
- `lightr.tasks.projectFilter` 旧值的迁移
