# PRD: 侧栏文件夹可收起展开

父任务：`10-21-task-project-picker`。设计：`../10-21-task-project-picker/design.md` §1。

## Goal

项目变多后侧栏一屏放不下；用户要能收起不关心的文件夹，把空间留给正在用的项目。

## Requirements

### R1 折叠入口
- 文件夹行左侧新增折叠箭头：收起时朝右，展开时朝下（旋转动画）。
- **点击箭头**切换折叠；**点击文件夹名 / 整行**保持现有「打开该项目」行为不变。

### R2 折叠效果
- 收起时不渲染该项目的会话列表。
- 文件夹行仍然显示：项目名、计数、悬浮的「新建会话」「移除项目」按钮。
- 收起且该项目存在生成中的会话时，计数旁显示一个蓝点。

### R3 状态记忆
- 折叠状态存 `localStorage`，key `lightr.sidebar.collapsedProjects`，值为项目 id 数组。
- 应用重启后保持。
- 读取失败（隐私模式 / 脏数据）按「全部展开」处理，不报错。

### R4 搜索联动
- 搜索框有内容时**忽略折叠状态**，命中的会话一律显示。
- 该文件夹行显示「N 个匹配」。
- 清空搜索后恢复原有折叠状态。

## Acceptance Criteria

- [x] **AC1** 点击箭头收起该文件夹，会话列表消失，文件夹行保留。
- [x] **AC2** 再次点击箭头展开，会话列表恢复。
- [x] **AC3** 点击文件夹名或整行（非箭头区域）仍然打开该项目（行为与改动前一致）。
- [x] **AC4** 收起两个文件夹后重启应用，两个仍是收起的。
- [x] **AC5** 收起状态下，该项目有生成中会话时计数旁出现蓝点。
- [x] **AC6** 搜索某个只存在于已收起项目里的会话时，该会话能显示出来。
- [x] **AC7** 清空搜索后，之前收起的文件夹重新收起。
- [x] **AC8** 空项目（0 个会话）的收起/展开无异常、不报错。
- [x] **AC9** 移除项目后，其折叠记录不影响其它项目。
- [ ] **AC10** `vue-tsc --noEmit` + `pnpm build` 绿。

## Out of Scope

- 「聊天」临时会话组的折叠
- 折叠状态同步到磁盘 / 跨设备
- 文件夹的拖拽排序
