# PRD: 新建/编辑任务对话框对齐 codeg

父任务：`10-20-task-board-codeg-ui`。设计：`../10-20-task-board-codeg-ui/design.md` §4。
参考：`../10-20-task-board-codeg-ui/research/codeg-ui-details.md` §3。

## Goal

建任务时视觉重心落在**标题**和**提示词**上，而不是一堆带边框的表单行；
引擎选择是一个带图标的下拉列表，能一眼看到当前选的是哪个引擎、也能换成别的。

## Requirements

### R1 标题
- 无边框输入，`text-lg font-medium`，占满宽度。
- 占位文案「任务标题」。

### R2 引擎下拉（用户明确要求）
- 触发器为 **pill 形态**：圆角胶囊、白底、细边框；左侧 16px 引擎图标、中间引擎名、
  右侧 `ChevronDown`（展开时旋转 180°）。
- 展开面板：白底卡片，每项一行（图标 + 名称），选中项显示对勾，hover 高亮。
- 点击面板外或按 Esc 关闭（现有行为保留）。
- 引擎列表来自 `engineStore.agents`；为空时显示「选择引擎」并禁用提交。

### R3 提示词
- 大文本框，`min-h-[6rem] max-h-[14rem]`，可纵向滚动。
- 占位文案说明「Agent 会收到这段描述」。

### R4 目标区
- 小号大写标题「目标」。
- 文件夹下拉（必选）。
- 下方一行说明文字：任务将在该文件夹中创建会话并执行。
- 不提供分支 / worktree 选择（本项目无 worktree 机制）。

### R5 页脚
- 右侧「取消」（ghost/描边）与「保存」（实心填充，校验不过或保存中禁用）。
- **不渲染模板按钮**：模板功能本轮不实现，也不放禁用占位（避免死 UI）。

### R6 校验
- 标题非空、提示词非空、项目必选、引擎必选。
- 校验失败文案显示在页脚上方，红色小字。

### R7 编辑模式
- 仅在 `todo` / `failed` 可编辑（沿用 `isTaskEditable`）。
- 编辑模式下项目不可改（任务已归属），引擎、标题、提示词可改。

## Acceptance Criteria

- [ ] **AC1** 标题输入无边框、字号明显大于正文，占据首行。
- [ ] **AC2** 引擎选择是下拉列表；展开后每项有图标与名称，选中项有对勾。
- [ ] **AC3** 点击外部或按 Esc 能关闭下拉面板，且不提交表单。
- [ ] **AC4** 提示词框高度落在 `6rem ~ 14rem` 区间，内容超出时内部滚动。
- [ ] **AC5** 「目标」区标题为大写小号风格；文件夹为下拉；说明文案取代 codeg 的分支说明。
- [ ] **AC6** 页脚只有「取消」「保存」，右侧对齐；保存为实心填充。
- [ ] **AC7** 标题、提示词、项目、引擎任一缺失时保存按钮禁用或提交报错并显示红字。
- [ ] **AC8** 编辑 `running` 状态的任务时不可打开编辑器（入口本就只在 `todo`/`failed` 提供）。
- [ ] **AC9** `vue-tsc --noEmit` + `pnpm build` 绿；`cargo check` 绿。
- [ ] **AC10** 新建任务成功后卡片出现在「待办」列（数据链路零回归）。

## Out of Scope

- 任务模板（保存/应用/删除）——本轮完全不实现，也不做占位 UI
- 富文本 / @ 引用 / 附件（codeg 的 `TaskMessageComposer` 能力）
- 模型 / 推理强度 / 模式选择（codeg 提示词框底部那排）
- 分支选择（本项目无 worktree）
